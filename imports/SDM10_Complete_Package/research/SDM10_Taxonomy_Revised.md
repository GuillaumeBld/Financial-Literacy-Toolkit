# SDM-10 Taxonomy Revision
## Layer 1: Financial Literacy Misconception Categories
## Generalizable Across Contexts (University, Bank, Corporate, Policy)

---

## Design Rationale

Layer 1 categories are financial literacy misconception families that recur across populations and contexts. A bank assessing clients, a university assessing students, and a corporate program assessing employees will encounter the same fundamental misconception types, even if the specific questions differ.

Layer 2 tags remain item-specific to each assessment instrument.

---

## Layer 1: Financial Literacy Misconception Categories

## Cross-Cutting Response Types (Not Misconceptions)

These are response patterns that occur across all categories. They are NOT misconception families; they describe the type of response, not the content.

| Code | Type | Description |
|------|------|-------------|
| KG | Knowledge Gap | Student has no knowledge of the concept (explicit IDK, blank, unfamiliar with terms) |
| SE | Selection Error | Student demonstrates correct understanding but selected wrong answer (misread, misclick, T/F reversal) |

These are combined with the category codes:
- `INF-01` = Misconception about inflation (lower inflation = falling prices)
- `INF-KG` = Knowledge gap in inflation (student does not know what inflation is)
- `INF-SE` = Selection error on an inflation item (student explains inflation correctly but chose wrong option)

## How to Use This for a New Financial Literacy Assessment

### Same Population, Different Questions

If you create a new set of financial literacy questions for the same population (e.g., QUIN 102 next semester):
- Layer 1 codes stay the same (the misconception families are stable)
- Layer 2 tags may change (different questions may surface different specific expressions)
- Run the same process: collect open-ended responses, review, derive new Layer 2 tags, map to Layer 1

### Different Population, Same Questions

If you administer the same 40+10 to a different population (e.g., bank clients, corporate employees):
- Layer 1 codes stay the same
- Layer 2 tags will mostly recur (same questions = same misconception expressions)
- New Layer 2 tags may appear (different populations may have different wrong models)
- Run a calibration round: review first 50-100 open-ended responses, add any new Layer 2 tags

### Different Population, Different Questions, Same Domain

If you build a completely new financial literacy assessment:
- Layer 1 codes stay the same (these are financial literacy misconception families, not question-specific)
- Layer 2 is fully regenerated
- The methodology transfers: administer, collect, review, tag, prompt

### Different Domain Entirely

If someone wants to apply this to biology, history, or another subject:
- Layer 1 must be rebuilt for that domain
- The STRUCTURE of the system transfers (three-way classification, two-layer taxonomy, scoring framework, reporting rules)
- The specific codes do not transfer

## AI Scoring Prompt Design Implications

The AI scoring prompt for each item needs:

1. **Item context:** The anchor question, correct answer, student's answer, subdomain
2. **Layer 1 codes relevant to this item:** Which misconception families could apply
3. **Layer 2 tags with example responses:** 3-5 real examples per tag from Test 1 data
4. **Classification instructions:** The decision tree (is it misconception, knowledge gap, or selection error?)
5. **Output schema:** The JSON structure with both Layer 1 code and Layer 2 tag

Example prompt structure (template, not final):

```
You are scoring a student's open-ended response on a financial literacy assessment.

ITEM CONTEXT:
  Question: [anchor question text]
  Correct answer: [key]
  Student's answer: [selected option]
  Student's confidence: High
  Subdomain: [subdomain name]

The student answered incorrectly with high confidence and was asked
to explain their reasoning.

POSSIBLE CLASSIFICATIONS:

Misconception families for this item:
  - INF-01: Lower inflation = falling prices
    Layer 2 tags:
      "lower_inflation_means_lower_prices": Student explicitly states
        prices decrease when inflation decreases.
        Examples: "If inflation decreases, prices will decrease"
                  "prices need to decrease to combat inflation"
      "deflation_confusion": Student describes deflation.
        Examples: "a decrease in general level of prices"
      "employment_link": Student connects to employment.
        Examples: "increasing employment, inflation should go down"

  - INF-KG: Knowledge gap in inflation
    The student writes "I don't know," gives no reasoning, or shows
    they have not encountered the concept.

  - INF-SE: Selection error
    The student's explanation demonstrates correct understanding of
    inflation lowering (prices rise more slowly, not fall) despite
    selecting the wrong answer.

DECISION TREE:
  1. Blank, IDK, or too short? → KG (idk_no_reasoning)
  2. Correct reasoning despite wrong answer? → SE
  3. Self-corrects? → SE (self_corrects)
  4. Specific wrong mental model? → Misconception (assign Layer 1 + Layer 2)
  5. Vague, no pattern? → KG (unclear_reasoning)

OUTPUT (JSON only):
{
  "diagnosis_type": "misconception | knowledge_gap | selection_error",
  "layer1_code": "INF-01 | INF-KG | INF-SE",
  "layer2_tag": "lower_inflation_means_lower_prices | null",
  "credit": 0 | 50 | 100,
  "classification_confidence": "high | medium | low",
  "evidence_quote": "key phrase from student response",
  "reasoning_summary": "one sentence: what the student believes"
}
```
